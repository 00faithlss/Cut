# Notas de versión de Cut

Cada actualización mantiene el estilo de Novedades: título breve y una frase clara por cambio, en español y orientada al usuario. Destacar funciones y correcciones relevantes; omitir arquitectura, dependencias, resultados de tests y detalles internos. Evitar promesas absolutas.

Actualizar conjuntamente la primera sección de CHANGELOG.md y los elementos de Novedades en src/native_ui/overlays.rs. Las notas de GitHub deben usar esa sección, sin listas automáticas de commits. Mantener el historial de versiones anteriores.

No añadir material de pruebas, conceptos o salidas de asistentes al repositorio. Conservar .git, .github y .cargo; assets/licenses contiene las licencias necesarias para el instalador.
